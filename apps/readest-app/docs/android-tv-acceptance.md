# 电视验收步骤

安装 `0.12.20-tv.4` ARMv7 签名包。原版 Readest 与 TV fork 数据独立；TV 旧测试包可直接升级。以下全程只用方向、确认、返回；菜单键再单独复验一次。

本轮优先验收：

- 冷启动书库没有选中框；第一次确认只选中第一本书，第二次才打开。一本书时，从书籍向上到顶栏最左侧，搜索框向右依次经过旁边按钮，不落到书籍上。至少两排三列书籍时，第二排第 3 本向上到第一排第 3 本，再向上到顶栏最左侧。
- 导入来源/网页导入等弹窗居中，深色/浅色均随原版主题。搜索和服务表单仍一次确认编辑、一次返回保留草稿。
- 朗读面板“语速”向右到“语音”；确认打开音色列表，返回恢复语音按钮。关闭面板后朗读继续；从底部“阅读进度”向上进入原版迷你播放器，再向右到“停止朗读”可以停止。
- 导入有目录的 TXT，稍等再开始朗读；与立刻开始相比观察首句与句间等待。跳到第 600 章附近，只应准备新位置，不能出现旧章节声音；695→696 继续朗读，上一章临时缓存自动清理。单元测试验证取消/清理，实机主要记录有无旧声、持续卡顿和资源异常。
- 开关书各重复三次、首次启动朗读一次，反馈是否仍有明显停顿及大致时长。Home 后再返回应用，不应有预生成常驻服务；断网预取不弹窗，当前本地阅读可继续；恢复网络后导航可重试。主动离线下载仍应重启可用。

1. **正文与目录**：打开本地 TXT/EPUB → 确认 → 目录。焦点应在当前章。上下浏览时正文不动，确认新章后回正文并停在新章。数千章书用章节序号查找/回当前章；无目录书显示进度替代。
2. **全宽单栏与原版面板**：新装及旧 TV 包首次升级后，TXT/EPUB 应全宽单栏分页，四周仅留阅读边距。正文确认后是原版顶部/底部工具栏；底部右三次到“字体和布局”，确认展开，上两次到字号滑块，左右改字号。返回先收起面板并回原按钮，再返回正文。顶部查看选项 → 设置 → 布局，分栏数左右切换 1/2/1；返回自动保存，重开书仍保留。深色主题下工具栏、菜单和设置应随主题变暗，不出现另写的白色菜单。进度面板百分比只预览，选“前往”才跳转，焦点留在滑块；“返回上一阅读位置”恢复跳转前位置。
3. **输入法**：搜索框聚焦不弹输入法，一次确认进入；输入后一次返回收起并保留内容，方向能直接移到其他控件。批注、TTS 服务表单重复。焦点在取消时确认绝不能保存/删除。
4. **播放模式**：顶部查看选项 → 开启滚动模式 → 自动滚动。确认暂停，上键打开控制，返回逐层退出且保留当前位置。快读重复。底部朗读打开音色/语速子页，返回到播放器再到正文；手动暂停后开关目录、设置不得自行恢复。
5. **选文/图片/排序**：整段选择后批注保存；精确选文改起点/终点、同章跨段并取消；图片进入平移后返回到缩放控件；书架/OPDS/词典排序用前移后移，不依赖拖拽。
6. **手机上传**：顶部查看选项 → 手机助手 → 开启。地址必须是实际 LAN IP 和端口。手机同网扫码，选 2 本（含中文 TXT），电视批准一次；收起页面继续，完成只入书库不打开。再检查拒绝一批、取消传输、停止新接收、关闭入口。
7. **手机配置**：手机“朗读服务”填写自己的服务/模型/音色/key → 试听 → 保存；电视选该音色朗读。改参数但不保存应只影响试听。编辑保留旧 key、替换/清除 key、删除服务分别验证。WebDAV/OPDS 页面保存后电视可见。
8. **持久化与授权**：重启 TV app，书籍和服务仍在。切 Wi-Fi/有线，二维码更新，旧手机授权失效；重新扫码可用。关闭/15 分钟过期同样失效。无网络时不显示 localhost/0.0.0.0/旧二维码。
9. **无官方依赖**：全新安装/空数据，不登录；网络屏蔽 Readest 所有域名后，启动、导入、本地阅读、设置、独立服务仍可用。主动下公共字体/示例书/Word Lens 只显示对应失败，无登录/会员/不断重试。恢复网络后手动重试，已下载资源断网重启仍可用。
10. **系统边界**：音量仍调系统音量，Home 回桌面；连续返回逐层退出，不困在输入或图片模式。外部文件选择器/OAuth 页面按电视实际系统验证。

代码自动化和桌面浏览器不能替代上述硬件验收。反馈时记录步骤编号、书籍格式、按键序列、预期和实际，以及关于页显示的 TV 版本与 WebView 版本。
